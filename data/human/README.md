# Free-written test comments

`comments.csv` holds 60 comments for test puzzles (10 per motif), written on 2026-10-19 by an AI assistant (Claude),
not by a person. They were written from each position's verified facts, stay inside the project grammar's
vocabulary, and avoid the generator's template wording where the grammar allows.

The pipeline calls this split "human" (see `prepare.py`); in results and the write-up it should be reported as
**AI-written, non-template comments**, not as human-written text. Replacing or extending this file with
genuinely human-written comments remains future work.
